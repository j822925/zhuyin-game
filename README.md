# 注音探險島

給平板使用的注音練習：單音聽辨、結合韻聽辨、拼音積木及同機雙人輪流。

## 目前交付狀態（2026-09-13）

新版已發布至 [正式遊戲](https://j822925.github.io/zhuyin-game/)，Google Apps Script 同步更新為部署版本 5（API v4）。學生密碼、搶答、15 號測試隔離及角色交易均已納入發布。首頁已成功讀取正式題庫；完整正式登入與存分驗收狀態見 `docs/release-20260913.md`。

此版仍分開單音、結合韻和拼音關卡，尚未加入每日星星上限、朗讀辨識與聲調關卡。老師的新需求及優先順序見 `docs/next-classroom-features.md`。

- 學生介面：大圖示、語音提示、雙人動物／精靈和藍橘分區。成人說明保留於 `teacher.html`。
- 15 號：老師測試。預覽可直接使用；新版後台上線後，練習另存「測試紀錄」，不會加入正式「過關紀錄」或每日學生名單。
- 搶答：同一畫面左右作答，聽完才解鎖。先答對 1 分，答錯鎖定該方本題；未搶到不算答錯。整場另存「搶答紀錄」，不混進全對／每日完成。
- 收藏：20 個原創毛絨風 PNG 角色（10 動物、10 精靈），兔子和狐狸為起始角色。角色表可擴充，沿用既有角色編號與收藏。設計與提示詞見 `docs/cozy-design.md`、`docs/cozy-prompts.json`。
- 題數與獎勵：每回合 10 題，輪流每人 10 題、搶答共 10 題。單音／結合韻全對 2 星、拼音全對 3 星，有錯當回合 0 星。一般每 3 個完整回合、拼音每 2 個完整回合各另給 1 毅力星；两類分開計次，中途離開不計次，重新整理不歸零。比賽贏 2、輸 1、平手各 1，不疊加單人全對；毅力星仍按關卡類型累積。新規則只影響新回合，舊星星／糖果不追溯扣除。
- 轉蛋：5 星星一次、可選角色池、同池等機率、允許重複。重複角色加 1 糖果；50 糖果自選兌換一個未擁有角色，有確認畫面，不涉及金錢。
- 預覽錢包：僅存本瀏覽器、依座號分開，不會搬入正式錢包。正式後台從已完成回合與「角色交易」計算餘額，以鎖和交易編號防止重送重扣。
- 新增慢速拼音 `audio/syllable-clear/`：44 音節，合成語速 -4、前停頓 200 ms、後停頓 600 ms，原版 `audio/syllable/` 保留比較。不是已通過教師審核的真人發音。
- 新增 4 個台灣中文語音提示；需要點按播放，不要求孩子讀文字。

已完成 41 項自動化測試，涵蓋新獎勵、角色表擴充、去重與舊資料相容。先前已完成預覽轉蛋、自選兌換、15 號選取及雙人交接驗證；新版外觀另做瀏覽器視覺檢查。沒有向正式後台插入測試成績。實際大屏多人觸控、跨裝置收藏、正式後台寫入仍需上線前驗收。

已發布四位數 PIN 驗證與私人後台密碼管理。切換座號與邀請對戰者都須驗證；成績、星星和轉蛋在後台驗證身分，不只是首頁遮罩。部署與安全邊界見 `docs/student-passwords.md`。試玩密碼預設 1234，可在老師頁修改（僅本瀏覽器）；正式密碼由老師在私人試算表設定。

iPad 橫向為主要版面，已確認 1024 × 768 的首頁、精靈收藏與雙人左右分區。未用實體 iPad Safari 驗證多人觸控、音訊自動播放或全螢幕支援。

## 教師操作

1. 在 Google 試算表的「今日任務」填入已教的單一注音。
2. 在「已教結合韻」A2 起填入已教的完整結合韻；不會以個別注音自動推定。
3. 每回合固定 10 題。先於 `teacher.html` 試聽拼音示範音，再勾選「拼音示範音已確認」。
4. 學生選座號及關卡。雙人輪流時兩位學生必須選不同座號，各答完整回合。
5. 「每日任務總覽」以完成紀錄統計；全對是當日至少有一回合答錯題數為 0。

`?demo=1` 是教師試玩，使用示範題庫，不寫入成績。

## 素材

- `audio/audio_F*.WAV`：原有 37 個單音。
- `audio/compound/*.mp3`：22 個結合韻，由使用者提供的影片擷取首次完整發音，略過片頭提示聲及第二次重複；裁切範圍見 `audio/compound-manifest.json`。
- `audio/syllable/*.wav`：44 個第一聲音節，使用 Windows Microsoft Hanhan Desktop（zh-TW）合成。屬待教師核對的示範素材，不宣稱真人錄音。音節／字詞對照見 `data/syllables.json`。
- 原始影片保留在本機專案外層的「結合韻影片」，不需上傳網站。

## 後台升級

將 `backend/student-auth.gs` 一起新增至原專案，並將 `backend/game-api.gs` 的 `doGet`、`doPost` 及輔助函式放入既有 Apps Script，保留每日總覽函式。先執行 `setupGameSettings` 和 `setupStudentPasswords`、授權編輯觸發器並設定學生密碼，再把現有網頁應用程式部署更新成新版本，沿用原網址。

新後台保留舊遊戲五個原始欄位結構，但不再允許未驗證的舊前端寫入，新增回合編號、關卡、耗時、首次答對題數與明細。用鎖及唯一回合編號避免網路重送重複計次。新前端須從後台查到該編號才顯示「已收到」，斷線時暫存並可重送。

前端僅使用座號；姓名由私人試算表對應。回合編號查詢只回覆是否存在，不回覆學生或成績資料。

目前單人／輪流關卡計入同一個每日「探險島」任務；搶答紀錄另存，不計入每日完成。若要按日期設定不同關卡或各關卡次數，需再加入日期化的任務表與任務編號。目前不包含兩台裝置的即時連線對戰。

## 本機預覽與測試

用任一靜態 HTTP 伺服器開啟專案資料夾，例如 `python -m http.server 8765`，開啟 `http://localhost:8765/?demo=1`。

`npm test` 執行測試。無需安裝前端依賴；Node.js 可直接執行 `node tests/core.test.js` 和 `node tests/backend.test.js`。

已驗證：第一週六音的八個拼音、未教結合韻隔離、干擾選項範圍、題目均衡、連點鎖定、回合完整性、重送去重與不公開姓名。UI 另以試玩模式完成單音、拼音及雙人結合韻整回合。
