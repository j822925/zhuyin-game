# 完整拼音題庫：組合清單與待確認事項

來源：外交部領事事務局「護照外文姓名拼音對照表」https://www.boca.gov.tw/cp-2-4226-c0eff-1.html ，2026-09-13 查閱。

此表去重後 409 個不分聲調音節。依本遊戲「聲符＋明寫韻符」的範圍，排除 37 個零聲母音節、7 個省略空韻的音節（ㄓㄔㄕㄖㄗㄘㄙ），得到 365 個組合：聲符＋單一韻符 201、聲符＋結合韻 164。這是指定參考表的統計，不代表所有文獻採用相同音節數或每個組合都有第一聲常用字。

資料位於 data/spelling-combinations.json。後續已擴充為 359 個試聽檔、352 組可出題；另外 7 組待核對、6 組待補可靠例字。不能把 365 組參考清單筆數當作已完成錄音數。詳見 vertical-spelling-20260913.md，原有 44 音檔未覆寫。

既有 poolFor('spelling') 已依老師教過的聲符及完整韻符篩選；只有 ㄧ、ㄠ 不會自動視為教過 ㄧㄠ。未來擴充實際音檔後，ㄈ／ㄌ／ㄧ／ㄨ 四格可開放 ㄈㄨ、ㄌㄨ、ㄌㄧ，不包含 ㄈㄧ。仍須按原 B3 示範音確認開關。

老師已確認：盡量用第一聲，難找時接受其他聲調，並在直式題目上顯示調號。新增音庫依此採自然例字聲調，不把非第一聲音檔標為第一聲。沒有修改 Google 題庫、密碼、紀錄或老師的確認開關。
