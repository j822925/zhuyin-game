# 登入連線修正

15 號原密碼已由正式後台接受，沒有重設或改寫密碼。先前正式瀏覽器曾出現連線失敗；更早的錯誤沒有保留原始回應，因此不把推測當成已確認原因。

- 統一 GET / POST 連線：每次獨立查詢參數、禁止快取、追蹤 Google ContentService 的暫時重新導向。密碼與登入憑證只在 HTTPS POST 本文，不放在網址、紀錄或程式碼中。
- 等候上限從 20 秒增為 45 秒，改用 AbortController 與計時器，不依賴較新 iPad 才支援的 AbortSignal.timeout。
- 不自動重送登入，避免失去回應時重複累計密碼錯誤。原有身分驗證、五次錯誤鎖定與伺服器每日獎勵限制維持不變。
- 只有後台明確回覆 invalid_pin 才顯示密碼錯誤。另區分暫時鎖定、連線逾時、網路／回應格式問題、後台程式錯誤；不把原始錯誤內容直接顯示給學生。
- 維持兒童圖像提示，完整說明放在輔助標籤與提示文字。

53 項自動化測試通過。正式瀏覽器驗收結果待完成後追加；尚未用實體 iPad Safari 測試。
