# 學生四位數密碼

## 狀態與上線順序

私人 Apps Script 已新增「學生密碼.gs」，未改動原正式 API。2026-09-13 老師完成授權後，已確認初始化執行完畢、「學生密碼」分頁建立，以及唯一一個 `studentPasswordEdit` 試算表編輯觸發器。01–15 號均已列入，目前狀態為待老師設定。

[開啟學生密碼分頁](https://docs.google.com/spreadsheets/d/1b8WYLHZdupEotCUKljM43vTEVHrF52TJpnYF7BGaV0o/edit?gid=193889082#gid=193889082)。正式密碼需由老師親自輸入；代理未設定或更改任何正式密碼。

本機前端及後台程式已實作；正式部署前必須完成私人試算表初始化與實機驗收。未部署時，不得宣稱舊正式遊戲已受到密碼保護。

1. 在原 Apps Script 保留每日總覽程式，更新 `backend/game-api.gs`，另新增 `backend/student-auth.gs`。
2. 執行 `setupGameSettings`、`setupStudentPasswords`。後者建立「學生密碼」分頁與 `studentPasswordEdit` 編輯觸發器。新增權限授權需由老師確認。
3. 老師在私人試算表每位學生的 C 欄設定四位密碼，包含 15 號教師測試帳號。可用開頭為 0 的密碼；不要輸入已用於銀行、手機或其他帳號的密碼。
4. 驗證已設定狀態；C 欄在成功套用後清空，D/E 欄顯示狀態和時間。忘記密碼時輸入新的四位數字，不提供原文查詢。
5. 協調部署前端及 Apps Script v4。新版不接受無驗證的成績或轉蛋，舊前端將無法繼續寫入；不要只更新其中一邊。原紀錄不刪除。需要逐一驗證登入、雙人驗證、存分、錢包、斷線重送及重新登入。

## 驗證規則

- 大數字鍵盤輸入四位後送出；密碼遮罩。取消則清除座號，不進入遊戲。
- 切換座號需再次驗證；兩人比賽要兩份各自對應座號的登入憑證。
- 正式密碼以隨機 salt 加 HMAC-SHA-256 摘要保存在私人 Script Properties，不置於 GitHub、前端或設定 API。
- 登入憑證只保存在該分頁記憶體，最多兩小時；重新整理需要再次登入。後台重設密碼後立即撤銷該生舊憑證。
- 每個座號連錯五次鎖五分鐘；重設可解除。以後台鎖保護嘗試次數，不讓並行请求繞過限制。
- 密碼與憑證只走 HTTPS POST 本文，不放網址；錢包、查詢、成績及轉蛋均需驗證。預覽 localhost 僅用示範密碼，不連正式帳戶。
- 不接受無密碼的舊版匿名寫入；未驗證或連線失敗時不降級繞過。正式跨來源 POST/回應需部署後實測，失敗時不得改成把密碼放 GET 網址。

## 保護邊界

四位數是方便低年級孩子使用的課堂 PIN，不等於高強度帳號安全。請保持試算表與 Apps Script 私人共享，不讓學生拿到編輯權限。試算表的修訂紀錄仍可能保留老師輸入過的密碼；清空輸入格不代表刪除所有修訂紀錄。

試玩模式的 1234 與「試玩密碼設定」只是本機演示，並非正式預設密碼，也不會修改正式資料。正式學生必須由老師設定後才能登入。
